# Third-party components

## WeChat QRCode models

The four unmodified model files and their complete upstream LICENSE in
`src/main/resources/org/example/tokenclient/wechat/` come from
https://github.com/WeChatCV/opencv_3rdparty/tree/wechat_qrcode.
Copyright (C) 2021 THL A29 Limited, a Tencent company.
The upstream license includes Apache-2.0 and third-party notices.
`WechatQrDecoder` pins the SHA-256 of each packaged model.

## Douyin a_bogus signing

`AbogusSigner.java` is a Java adaptation of `src/ab_sign.py` from
https://github.com/jackspeng/DouyinLiveRecord, as referenced by
https://github.com/cjh-better/wuthering-waves-scancer/blob/master/utils/abogus.py.
SM3 is supplied by Bouncy Castle; the Java port preserves the reference wire format.
Test vectors were generated by the Python implementation at fixed timestamps.
